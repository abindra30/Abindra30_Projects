A collection of learning projects exploring modern Microsoft AI and cloud technologies.

## Projects

### 🤖 FoundryAgentConsole — Azure AI Foundry + Semantic Kernel (.NET 10)

A stubbed-out **.NET 10 console app** that wires up an AI agent using Microsoft Semantic Kernel to an Azure AI Foundry project. The code is intentionally incomplete so you can learn by filling in the TODOs yourself.

| | |
|---|---|
| **Framework** | .NET 10 |
| **AI SDK** | Semantic Kernel 1.72 |
| **Cloud** | Azure AI Foundry |
| **Auth** | Azure Identity (`DefaultAzureCredential`) |

📖 **[Getting Started Guide](FoundryAgentConsole/GETTING_STARTED.md)** — step-by-step from Azure account creation to running a live chat session.
